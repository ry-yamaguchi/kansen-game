# kansen-game

ブラウザで遊ぶ**感染拡大シミュレーション**ゲーム。
プレイヤーは感染源の側に立ち、変異を重ねながら世界へ広がっていく——という方向で構想中である。

| 項目           | 内容                                 |
| -------------- | ------------------------------------ |
| プラットフォーム | ブラウザ                             |
| 言語           | TypeScript                           |
| 状態           | 準備中（企画・設計・実装はこれから） |

## 開発

実装は [Kiro](https://kiro.dev) で進める。
要件・設計・タスクは Kiro の spec として `.kiro/specs/` 以下に置き、
プロジェクト共通の指針は `.kiro/steering/` に置く。
