# kansen-game

ブラウザで遊ぶ**感染拡大シミュレーション**ゲーム。
プレイヤーは病原体の側に立ち、架空の島国に静かに広がり、変異を重ねて全人口への到達を目指す。
1プレイ5〜10分の使い切りである。

| 項目             | 内容                                 |
| ---------------- | ------------------------------------ |
| プラットフォーム | ブラウザ                             |
| 言語             | TypeScript（Vite / Canvas 2D）       |
| 状態             | 準備中（企画のみ。実装はこれから）   |

現実の感染症を予測・再現するものではなく、ゲームである。舞台・地名・病名はすべて架空である。
