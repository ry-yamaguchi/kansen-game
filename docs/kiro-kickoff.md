# Kiro へ最初に渡す文

Kiro でこのリポジトリを開き、最初のチャットに下をそのまま貼る。

---

このリポジトリで、ブラウザで遊ぶ感染拡大シミュレーションゲームを作ります。

まず `.kiro/steering/` の5ファイルと `docs/concept.md` を読んでください。
steering はプロジェクトの前提、concept.md は企画の出発点です。

読んだうえで、**実装に入る前に**次の順で進めてください。

1. 企画メモを読んで疑問点・矛盾点・決めきれていない点を挙げる（`docs/concept.md` の
   「10. 未決」も含めて）。私と決めてから spec に落とす。
2. spec（要件 → 設計 → タスク）を作る。対象は v1 のスコープに限る。
   v1 に入れないものと書いてあるものは、要件に入れない。
3. 実装は `src/sim/`（シミュレーション中核）から始める。画面はまだ作らない。
   ヘッドレスで回して勝敗が割れることを確かめてから描画に進む。

全部日本語でお願いします。
