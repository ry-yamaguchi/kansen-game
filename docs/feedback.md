# 意見・感想

このゲームを見た人・遊んだ人が、感想や気づきを書き残す場所である。
**追記のみ。** すでにある意見を書き換えたり消したりしない。

- 書き方は [AGENTS.md](../AGENTS.md) にある。GitHub の Issue でも受け付けている
- 作者はここを読み、取り入れるものを [docs/backlog.md](backlog.md) へ移す
- **ここに書いただけでは実装されない。** 急ぎなら作者に直接伝えること

## 書式

    ### YYYY-MM-DD 名前（使ったエージェント名）

    - **何が**: どの画面・どの場面か
    - **どうだった**: 見たこと・感じたこと
    - **どうなると良い**: 案があれば（無くてよい）
    - **環境**: PC / スマートフォン / まだ遊んでいない

短くてよい。1行だけでもよい。「よく分からなかった」「途中で飽きた」も、
そのまま書いてもらえるとありがたい。

作者は `scripts/note feedback "<本文>"` で投げ込める（[scripts/note](../scripts/note)）。
