# 設計: エクストラステージ「新商品」（広める側を遊ぶ）

2026-09-24。作者の案「商品やサービスを広めたい（今回とは真逆）というエクストラステージ」の設計である。
根拠は [docs/research.md](research.md) の E 節。

## 一言で

同じ街・同じ人・同じ時間帯で、**今度は広げたい**。新しい店の商品を、口コミで街に広める。
いつもは「止める」ために読んでいた人の流れを、「広める」ために読む。

## 感染症と真逆になるところ

| 項目         | 感染症（いつものモード）          | 新商品（エクストラ）                          |
| ------------ | --------------------------------- | --------------------------------------------- |
| 目的         | 広がりを抑える                    | **広げる**                                    |
| うつり方     | 1回の接触でうつる（単純な伝染）   | **複数の人に勧められて初めて試す**（複合的な伝染） |
| 3つの状態    | 未感染 → 感染 → 回復              | 未体験 → 愛用中 → 飽きた                      |
| 7割5分に達すると | 崩壊（負け）                  | **ブーム到来（勝ち）**                         |
| 全員いなくなると | 終息                           | **定着せず（負け）**                           |
| 代償の指標   | 社会活動（抑えるほど下がる）      | **好感度**（押しつけるほど下がる）            |
| 得点         | 抑えた量 × 社会活動               | **広めた量 × 好感度**                         |

## うつり方: 複数の人に勧められて初めて試す

- 一人ひとりに「何人に勧められたら試すか」（1〜4人）を持たせる。普及の5分類に沿って配る:
  新しもの好き（1人で試す）少数、初期採用者（2人）、多数派（2〜3人）、慎重派（4人）
- 「勧められた」は、愛用中の人と一定時間そばにいたこと。**同じ人に何度勧められても1人と数える**
- だから**人が固まる場所**（昼の広場、職場、学校）で火がつきやすい。街を読む価値が、感染症とは違う形で生まれる
- 愛用中の人は、しばらくすると飽きる（飽きた人はしばらく勧められても試さない）。広め続ける工夫が要る

## 道具（感染症の道具の裏返し）

| 道具     | 裏返しの元     | 効果                                                                 | 代償                          |
| -------- | -------------- | -------------------------------------------------------------------- | ----------------------------- |
| 試供品   | ワクチン       | 範囲の人がその場で試す（愛用中になる）                               | ポイント                      |
| イベント | 封鎖           | 置いた場所に、周りの人が一時的に集まる（勧め合う場を作る）           | ポイント                      |
| 広告     | ロックダウン   | 数秒間、街の全員が試しやすくなる（勧められる人数が1人少なくて済む）  | **好感度が下がる**。使うたびに効きが落ち、下がり方は大きくなる（広告疲れ） |

- 好感度が下がると、飽きるのが早くなり、試しにくくなる。**押しつけすぎると逆効果**（心理的リアクタンス）
- 最善手は「広告を打ちまくる」ではなく、**人気者に試供品を渡し、昼の広場でイベントを開き、口コミに任せる**こと

## 人の個性との相性

人の個性（特性持ち4人）が、このステージでは意味を変える:

| 特性（感染症での呼び名） | 新商品での呼び名 | 効果                                             |
| ------------------------ | ---------------- | ------------------------------------------------ |
| よく人と会う人           | 顔の広い人       | 勧める相手が多い                                 |
| 人気者                   | インフルエンサー | その人に勧められると**2人分**と数える（初期採用者は周りに影響する） |
| 医療スタッフ             | 辛口レビュアー   | 近くの愛用者が早く飽きる（**プレイヤーの敵**になる） |

## 画面

- 開始画面のモード選択に、3モードの下へ「エクストラ」として置く。最初から選べる
- 3状態の色は、感染症の赤系をやめ、明るい色（試した人が明るく光る）にする
- 結果画面は「普及率」「最大同時愛用者」「好感度」を出す

## 作り方の見込み

いまの仕組みの多くを流用できる（街・人・時間帯・3つの道具の枠・得点の枠）。新しく要るのは:

1. 複合的な伝染（勧められた人数を数える）
2. 道具3つの裏返しの効果
3. 勝ち負けの裏返し（ブーム到来／定着せず）と、得点の裏返し
4. 見た目と文言

人の個性とバランスの取り直しを先に済ませ、そのあとに着手する。
