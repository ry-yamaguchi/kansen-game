# 要望リスト

**作者（Ryosuke）がやってほしいことを、思いついた順に書き足す場所である。**
形式は気にしなくてよい。1行でよい。優先順位は Kiro が作者に確認する。

作者は `scripts/note backlog "<本文>"` でも足せる（[scripts/note](../scripts/note)）。

Kiro はセッション開始時にこのファイルを読み、未完了（`[ ]`）の上から着手する。
完了したら `[x]` に変え、その作業のコミットに含める。
運用の詳細は [.kiro/steering/workflow.md](../.kiro/steering/workflow.md) にある。

---

## いま進めるもの

- [ ] MVP を完成させる（人が動く → 感染する → 介入できる → 勝敗が決まる、まで遊べる状態にする）

## 次にやること

- [ ] GitHub Pages で公開し、スマートフォンから URL で遊べるようにする
      → Pages の設定とワークフローは作者が用意する。`package.json` ができた時点で作者に依頼すること
- [ ] MVP を作者が実際に触り、追加要素（特性持ちのキャラクター・ランダムイベント・コンボ演出）の
      どれが面白さに効くかを一緒に決める
- [ ] Issue の作成画面を一度開き、意見フォームが正しく表示されるか作者が確かめる

## 検討中（着手しない）

- [ ] スコアの保存・ランキング（外部バックエンドを作らない方針との兼ね合いを先に決める）
