# 設計: 街と目的地のある盤面

2026-09-23。作者のプレイ所感を受けた作り直しの設計である。

## なぜ作り直すか

作者が遊んだ所感:

> 対処するものが多すぎて雑に対応するようになってしまう。
> もう少し数を減らしつつ動きを複雑にするなどしてゲーム性を見直して欲しい。
> 障害物（街など）などを設置して移動が変わるようにして欲しい。

いまは85人がランダムに漂うだけで、一人ひとりを追えず、「どこに打つか」が「赤い点が多い所」以上の意味を持たない。
**少人数が目的を持って街を歩く**ようにすれば、人の流れが読め、「どこに介入するか」が
駅・広場・交差点といった**場所の判断**になる。遊びの核（どこに、いつ介入するか）に近づく。

## 作者と決めたこと

| 項目       | 決定                                                     |
| ---------- | -------------------------------------------------------- |
| 人数       | 30人前後（いまの約3分の1）                               |
| 動き       | 目的地を行き来する。時間帯で行き先が変わる               |
| 隔離       | **通れなくする**。封鎖した場所を人が避けて迂回する       |
| 街の形     | **毎回同じ**。駅や広場の位置を覚えて、守り方を磨ける     |

## 盤面

- 世界の大きさは**固定**する（横長 1000×600）。画面の縦横比に合わない分は余白にする
- **縦長の画面（高さ > 幅）では、同じ街を90°回した盤面（600×1000）を使う**。
  スマートフォンでも同じ街で遊べる
- 街は **5列×3行の区画**（縦長では3列×5行）。区画の間と外周が通りである（幅は70前後）

区画の役割（横長のときの並び）:

```
 住宅   学校   住宅   職場   住宅
 住宅   住宅   広場   住宅   住宅
 住宅   住宅   住宅   住宅   駅
```

- **住宅は建物であり、中に入れない**（障害物）
- **場所（広場・駅・学校・職場）は中に入れる。** 人はその中を小さく歩き回りながら滞在する
- 広場は中央。昼に人が集まる。大型イベントもここに人を集める
- 駅は角。**外からの感染者は駅から入ってくる**（いまの「画面の端から」をやめる）。駅を押さえる価値が生まれる

## 人

- **30人。** 一人ひとりに「家」（住宅区画に面した通り沿いの点）と「通う先」（学校か職場）を割り当てる
- 時間帯（75秒を3つに分ける）:

| 時間帯 | 時刻      | 行き先                         |
| ------ | --------- | ------------------------------ |
| 朝     | 0〜25秒   | 家 → 学校・職場                |
| 昼     | 25〜50秒  | → 広場（一部は駅）             |
| 夕方   | 50〜75秒  | → 家                           |

- 出発の時刻には一人ずつ数秒の差をつける（全員が一斉に動き出さない）
- **経路は通りの上を通る。** 交差点を節点とする格子で最短経路を探し、交差点をたどって目的地へ向かう。
  通りの中では左右に少しずらして歩き、全員が一本の線に重ならないようにする
- 着いたら、その場所の中を小さく歩き回って次の時間帯を待つ
- 速さは、盤面の端から端まで10秒前後で歩ける程度にする（1回の移動が5〜10秒で済み、滞在する時間が残る）

## 感染

接触の判定は今のままでよい。人が集まる場所（広場・駅・学校・職場・交差点）で自然に起きやすくなる。

## 介入（段階2で変える）

- **隔離＝封鎖。** 置いた円の中へ、外の人は入れない。中の人は出られない。
  経路探索は封鎖された所を避けて迂回する。迂回路が無ければ手前で待つ
- 封鎖の境界をまたいだ接触は起きない。**中の人同士は接触する**（健康な人を巻き込むのが代償）
- 「置いた瞬間に捕まえた感染者の数で効き目が決まる」規則は**外す**。
  通れなくする効果は、中に人がいなくても働くためである
- 所構わず封鎖し続けるのを抑えるのは、同時に置ける数（3つ）と社会活動の低下である
- ワクチン・ロックダウンは今のまま

### 前歴と歯止め（重要）

**「通れなくする隔離」は、2026-09-17 に Kiro が一度試して取り下げた方式である。**
当時は何もない平面で、中の人を閉じ込め外の人を押し出す「壁」にしていた。塞いだぶん外側が
混み合い、**隔離するほど外の感染が増える逆効果**になった（`engine.ts` の `updateZoneMembership` の
コメントに記録がある）。

街では押し出すのではなく別の通りへ迂回するので、同じ失敗にはなりにくい。ただし次の形で再発しうる:

- **迂回路が無い人が封鎖の手前に溜まり、そこが新しい密集地になる**
- 迂回した人が1本の通りに集中し、その通りで感染が増える

歯止め:

- 迂回路が無い人は封鎖の手前で待たず、**行き先を変える**（家へ帰る、別の場所へ行く）
- バランスの取り直しでは「隔離を使うほど、封鎖の外の感染が増えていないか」を必ず測る

## 画面

- 区画を描く。住宅は暗い塗り、場所は薄い色に名前（広場・駅・学校・職場）を添える
- **時間帯が変わったら知らせる**（既存の通知の仕組みを使う。例:「昼になりました。人が広場へ向かいます」）
- HUD に今の時間帯を小さく出す。スマートフォンの狭い HUD を崩さないこと
- 開始画面の説明文を街に合わせて直す

## 進め方

各段階で**遊べる状態を保って公開**し、作者が触れるようにする。

1. **盤面・人・時間帯・駅からの流入**（隔離は今の仕組みのまま）
2. **隔離＝封鎖**
3. **バランスの取り直し** — `npm run balance` で PC とスマートフォンの両方を測る。崩壊率は100試合で比べる。
   目標は今と同じ（放置は崩壊し、上手く打てば守れる。盤面を読まない打ち方が最善にならない）

## 変えないもの

- `src/sim/` は純粋・決定論のまま（乱数は `state.rng` から。CLAUDE.md 掟2）
- スコアの計算式
- 3つのモード（感染症・噂話・悪感情）。街は3モード共通で、広がるものだけが違う
