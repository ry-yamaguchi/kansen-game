# 企画メモ — 感染拡大シミュレーション

作成 2026-09-17。**これは決定ではなく出発点である。** Kiro との設計で変えてよいが、
「遊びの核」と「v1 に入れないもの」を動かすときは作者の判断を仰ぐこと。

## 1. 一言で

プレイヤーは病原体になり、架空の島国に静かに広がる。人類に気づかれる前にどこまで広げられるか、
どこで牙を剥くかを選ぶ、1プレイ5〜10分の使い切りシミュレーション。

## 2. 遊びの核

**「静かに広げる」と「牙を剥く」が真正面から衝突する。**

- 致死率や目立つ症状を上げると、人類に発見されてワクチン開発が始まり、都市が閉鎖される。
  広がる前に感染源そのものが死に絶えることもある。
- かといって無症状のまま広げ続けても、決着はつかない。
- **どこで切り替えるかがプレイヤーの腕**であり、毎回そこで迷うようにする。

この1点が成立していれば、絵が粗くてもゲームになる。成立していなければ、絵をどれだけ作っても
ならない。したがって最初に確かめるのはここである。

## 3. 舞台

架空の島国「ヤマト島」。12都市。実在の国名・地名・病名は使わない
（ゲームであり、現実の予測ではないため）。

都市が持つ値:

| 値       | 効き方                                       |
| -------- | -------------------------------------------- |
| 人口     | 感染の上限と、得られるポイントの量           |
| 気候     | 寒冷／温暖。対応する耐性がないと伝播が落ちる |
| 医療水準 | 発見の早さ、回復率、ワクチン研究への寄与     |
| 交通ハブ度 | 他都市へ運ぶ量                             |

都市どうしは陸路・海路・空路で結ぶ。空路と海路は人類側に閉鎖されうる。
マップは `src/data/` の JSON に置き、都市を増やすのにコードを触らなくてよい形にする。

## 4. 時間とシミュレーション

- 1ティック = 1日。標準のプレイで200〜400日。速度は 一時停止 / 1倍 / 2倍 / 4倍。
- 都市ごとに **SEIR + 死亡** を回す。
  - S 感受性 → E 潜伏 → I 発症 → R 回復、および I → D 死亡
  - 感染力 β・潜伏の長さ・回復率・致死率は、購入した能力から算出する
- 都市間は交通量に応じて感染者を運ぶ。ロックダウンと路線閉鎖でこの量が落ちる。
- 乱数はシード付き。同じシードと同じ操作からは同じ結果が出る。

## 5. プレイヤーの操作

新規感染者数と新規都市への到達で **変異ポイント** を得て、能力を買う。

| 系統 | 例                                                     |
| ---- | ------------------------------------------------------ |
| 伝播 | 飛沫、空気感染、水系、動物媒介、寒冷耐性、高温耐性     |
| 症状 | 咳、発熱、嘔吐、肺炎、臓器不全（致死率↑・発見されやすい） |
| 耐性 | 薬剤耐性、遺伝子変異（ワクチン開発を遅らせる）         |

- 症状は**売り戻せる**（一部ポイントが戻る）。試して戻せることが、迷う楽しさを支える。
- 初期の感染都市はプレイヤーが1つ選ぶ。ここで難度が変わる。

## 6. 人類側の対抗

- **発見**: 累計の発症者が閾値を超えると発見され、ワクチン開発が始まる。
  致死率と症状の派手さが閾値を下げる。
- **ワクチン進捗**: 未感染都市の医療水準の合計で進む。100% で敗北。
  都市を感染させるほど研究力は落ちる（＝進行を止めるにも広げる必要がある）。
- **ロックダウン**: 感染率が高い都市は移動量が落ちる。空港・港が閉じる。

## 7. 勝敗

- **勝ち**: 全都市で感受性人口が尽きる（全人口が感染を経験した）
- **負け**: ワクチンが完成する / 感染者が0になる
- 結果画面に、到達日数・死者数・最大同時感染者数・発見された日を出す

## 8. v1 のスコープ

作るもの: 固定マップ1つ（12都市）、SEIR と都市間伝播、能力15〜20項目、
ワクチン進捗とロックダウン、Canvas の地図と都市詳細、勝敗と結果画面。

**入れないもの**: 難易度の複数化、実績、複数の病原体タイプ、実在の地図、セーブとロード、
音、モバイル最適化、オンライン要素。

## 9. 最初にやること（順番に意味がある）

1. **`src/sim/` だけを作り、ヘッドレスで回す。** 画面はまだ作らない。
2. シードを変えて数十回流し、次を数字で確かめる。
   - 何もしなければ負けること
   - 全振りで致死率を上げると自滅すること
   - 「静かに広げてから牙を剥く」で勝てること
   - 勝敗が割れること（いつも勝つ・いつも負けるはバランスが壊れている）
3. ここが成立してから、初めて Canvas の描画に進む。
