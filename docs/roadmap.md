# ロードマップ

## 🔖 いまの状態（2026-09-23）

**Kiro での開発は 2026-09-17 で終わり、Claude Code が引き継いだ。**

- 遊べる状態で公開済み: <https://ry-yamaguchi.github.io/kansen-game/>
  （開始 → 介入 → 結果画面 → もう一度プレイ まで通る。PC・スマートフォンとも表示は崩れない）
- モードは3つ（感染症・噂話・悪感情）。対策は隔離エリア／ワクチン／ロックダウン
- スコアは「感染の抑制 × 社会活動の維持 × ピーク補正 + 残ポイント」の掛け算
- コードは約3,400行。`src/sim/` が中核で、描画と画面は分かれている
- **テストは無い。** Vitest も入っていない（引き継ぎ時点。いま整備中）
- **乱数がシード付きでない。** `src/sim/engine.ts` が `Math.random()` を直接呼んでおり、
  バランス変更の効果を測れない（いま整備中）

### いちばんの問題

**「判断するゲーム」が数字の上で成立していない。**（2026-09-23 に `npm run balance` で計測）

| 条件           | 抑えた割合 | スコア |
| -------------- | ---------- | ------ |
| 感染症・放置   | 59.0%      | 2,249  |
| 感染症・簡易AI | 62.8%      | 2,860  |
| 噂話・放置     | 75.5%      | 6,074  |
| 噂話・簡易AI   | 80.2%      | 6,241  |

- **放置してもほぼ同じ点が出る。** 噂話モードは差が +2.7% しかない
- **「隔離連打」(3,070) が「考えて打つ簡易AI」(2,860) より強い。** 考える意味が無い
- 手数は9回で頭打ち。作者が遊んだときも 258 ポイント中 58 しか使わず 200 余った。
  **有限のはずの対策ポイントが、制約として効いていない**

## 次にやること

1. **土台**（着手中）— シード付き乱数の導入、Vitest とテストの整備。
   これが無いとバランスの変更が効いたのか運なのか区別できない
2. **バランス**（作者の優先度 1）— 放置と介入の差を作る。連打より判断が強い状態にする。
   変更の前後で `npm run balance` を必ず取る
3. **演出・手応え**（作者の優先度 2）— 連鎖の CHAIN 表示、危機の OUTBREAK 表示。
   介入が効いた実感が薄いのを補う
4. **人の個性**（作者の優先度 3）— スーパースプレッダー・人気者・慎重な人・医療スタッフ。
   見た目で判別できるようにする。盤面を読む価値が生まれる
