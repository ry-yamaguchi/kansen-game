### バランスの現在値（100試合ずつ。本気AIの崩壊率）

| モード | 放置 | 本気AI 0.5秒 | 本気AI 3秒（人間に近い） |
| ------ | ---- | ------------ | ------------------------ |
| 感染症 | 94%  | 16%          | 34%                      |
| 噂話   | 76%  | 18%          | 26%                      |
| 悪感情 | 71%  | 17%          | 7%                       |

スマートフォン（縦長）も同じ盤面を使うので、ほぼ同じ値になる（19% / 29% / 11%）。
**上手な人でも3回に1回ほど負ける難しさ**である。作者が遊んで、重すぎないかを判断する。

### 残っている課題

- 噂話モードで、放置のスコアが本気AIの約67%ある（目標は55%未満）。崩壊はするが、点の差が小さい
- 感染症モードで「混合連打（3ツールを順に打つだけ）」と本気AIがほぼ同点（差0.3%）
- 上手さの正体がまだ「社会活動を削る手を我慢すること」に寄っている。打たないことが上手さだと、
  上達を実感しにくい → 演出で補う

### 分かったこと・取り下げた見立て

- ~~考えるより連打が強い~~ → 誤り。比較対象の簡易AIが弱かっただけで、よく考えるAIは連打に勝つ
- ~~対策ポイントが余っている~~ → 誤り。速く打てばほぼ使い切る。手数の上限を決めているのはポイント
- ~~密度を揃えれば、画面の大きさが変わっても同じゲームになる~~ → 誤り。人数が少ないと感染の山が揺れて崩壊しやすい
- ~~流入と初期感染者を人数に比例させれば公平になる~~ → 試したら噂話の崩壊が39%→72%に悪化した。
  ばらばらに入ってくる感染者が、感染の波の同期を崩す役もしていた
- **20試合では崩壊率の比較に足りない**（誤差±10%ほど）。崩壊率で判断するときは100試合で取る

## 次にやること

作者が遊んだ所感（2026-09-23）: 対処するものが多すぎて雑に対応してしまう。数を減らし、動きを複雑にし、
街（障害物）で移動が変わるようにしてほしい。→ **街と目的地のある盤面に作り直す。**
設計は [docs/design-city.md](design-city.md)。作者と決めたこと: 30人前後／目的地を行き来＋時間帯で流れが変わる／
隔離は通れなくする（封鎖・迂回）／街は毎回同じ。

1. ~~**段階1: 街・30人・目的地を行き来する動き・時間帯・駅からの流入**~~ — 完了（2026-09-24）。
   人が学校・職場に集まると接触が数倍に増え、放置で12秒で崩壊したため、感染の速さの全体倍率
   `exposureScale` を0.25にした（放置で約40秒で崩壊する）
2. ~~**段階2: 隔離＝封鎖。**~~ — 完了（2026-09-24）。経路探索が封鎖を避けて迂回し、行けなければ
   家 → 開いている場所 → その場 の順に行き先を変える（封鎖の縁に溜まらない歯止め）。
   計測では隔離を使うほど崩壊が減り、Kiro のときの逆効果は出ていない。
   残課題: 噂話では本気AIの崩壊が 7/20 と多め（本気AIの打ち方が旧来の隔離に合わせた作りのまま）。
   阻まれ続けた人が行き先を選び直す安全網は、テストの場面では使われておらず変異試験を生き残った
3. ~~**人間臭さと人の個性**~~ — 完了（2026-09-24。作者了承済み）。振る舞い5つ（どこで広がるか・体調が悪くても出勤・
   自粛・自粛疲れ・噂話の訂正は予防が効く）と、特性持ち4人（よく人と会う人×2・人気者・医療スタッフ）。
   副作用で悪感情が簡単になった（放置の崩壊 2/20）。以下は当時の説明 — 研究メモ [docs/research.md](research.md) の「取り入れる」。
   モードごとに広がる場所を変える（感染症は場所・悪感情は通り）、体調が悪くても出勤する、
   感染が目に見えると自粛し落ち着くと戻る、ロックダウンは使うたびに効きが落ちる、
   特性持ちの人（注意すべき対象は4人以内）
4. ~~**段階3: バランスの取り直し**~~ — 完了（2026-09-24）。100試合ずつ（PC）で、何もしない 89〜92%・
   上手な人（3秒に1手）25〜39% が崩壊する。スマホとの差は最大9ポイント。崩壊ラインを 63〜66% に下げ、
   悪感情と噂話の感染圧を上げ、対策ポイントの回復を増やした。**急いで打つより見極めて打つほうが強い**
   （0.5秒ごと 40% 対 3秒ごと 25%。打てる回数は同じなので、急ぐと序盤に使い切る）。
   届かなかった目標: 「ふつうの人（5秒に1手）で45〜65%」— 実測19〜42%で簡単寄り。作者が遊んで判断する。
   以下は当時の説明 —
   作者の所感（2026-09-24）: 街にしてから「雑になる」は解消したが、**簡単になったかもしれない**。
   人間並みの反応（3秒・5秒に1回）で測り、上手な人でも時々負ける難しさに戻す
5. ~~**エクストラステージ「新商品」**~~（作者の案 2026-09-24。E1〜E4 完了、公開済み）— 広める側を遊ぶ、感染症の真逆のモード。
   1時間ずつの区切り: ~~E1 勧められた人数で試す仕組み・状態・勝ち負けと得点の裏返し~~（完了 2026-09-24。
   既存3モードの計測は変更前と完全一致）→ ~~E2 道具3つの裏返しと好感度~~（完了）→
   ~~E3 画面（開始画面・結果画面・色）~~（完了。開始画面の「エクストラ」から遊べる）→
   ~~E4 バランス~~（完了 2026-09-25）。100試合（PC・3秒ごと）: 放置はブーム1%・定着せず98%、広告連打はブーム0%で最低点、
   試供品のみ 9,859、**試供品＋昼の広場のイベント 10,183（最高）**、本気AI 9,800。
   直したこと: ブームで終わると点が下がる不具合／試供品でその場で試すのは新しもの好きだけ／
   インフルエンサーは必ず新しもの好き／イベントの中では勧め合いが倍の速さ。
   残課題: インフルエンサー狙いの効き目が小さい（本人のいる場所を見ずに渡す打ち方の問題と見ている）。
   上手な打ち方のブーム到来 65〜70% で、狙い（35〜60%）よりやや簡単。作者が遊んで判断する
   設計は [docs/design-extra-stage.md](design-extra-stage.md)。複数の人に勧められて初めて試す（複合的な伝染）、
   広告は押しつけると好感度が下がる（リアクタンス）
6. ~~演出・手応え（CHAIN / OUTBREAK）~~ — 完了（2026-09-25）。1.5秒以内に続く感染を連鎖として数え「CHAIN ×N」、
   新しい感染の勢いが閾値を超えると中央に「OUTBREAK!」（新商品は「口コミ ×N」「BUZZ!」）。
   打った手はその場に「+N人を守りました」「隔離 N人」などを出す。演出は表示だけで、計測の全出力は変わらない

人の個性は作者了承済み（2026-09-24）: 見た目で区別する特性持ちは4人まで（よく人と会う人×2・人気者・医療スタッフ）。
「慎重な人」は特性にせず、全員が少しずつ持つ性格として自粛の振る舞いに溶かす。

済んだこと（2026-09-25）: 作者の依頼でキャラクターを見分けやすくした。人を1.5倍の大きさで描き（描画だけ）、

緑の輪＋十字のバッジ＝医療スタッフ）。開始直後の4秒だけ、特性持ちの頭上に呼び名の名札を出す。
