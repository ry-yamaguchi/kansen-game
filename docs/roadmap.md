### バランスの現在値（100試合ずつ。本気AIの崩壊率）

| モード | 放置 | 本気AI 0.5秒 | 本気AI 3秒（人間に近い） |
| ------ | ---- | ------------ | ------------------------ |
| 感染症 | 94%  | 16%          | 34%                      |
| 噂話   | 76%  | 18%          | 26%                      |
| 悪感情 | 71%  | 17%          | 7%                       |

スマートフォン（縦長）も同じ盤面を使うので、ほぼ同じ値になる（19% / 29% / 11%）。
**上手な人でも3回に1回ほど負ける難しさ**である。作者が遊んで、重すぎないかを判断する。

### 残っている課題

- 噂話モードで、放置のスコアが本気AIの約67%ある（目標は55%未満）。崩壊はするが、点の差が小さい
- 感染症モードで「混合連打（3ツールを順に打つだけ）」と本気AIがほぼ同点（差0.3%）
- 上手さの正体がまだ「社会活動を削る手を我慢すること」に寄っている。打たないことが上手さだと、
  上達を実感しにくい → 演出で補う

### 分かったこと・取り下げた見立て

- ~~考えるより連打が強い~~ → 誤り。比較対象の簡易AIが弱かっただけで、よく考えるAIは連打に勝つ
- ~~対策ポイントが余っている~~ → 誤り。速く打てばほぼ使い切る。手数の上限を決めているのはポイント
- ~~密度を揃えれば、画面の大きさが変わっても同じゲームになる~~ → 誤り。人数が少ないと感染の山が揺れて崩壊しやすい
- ~~流入と初期感染者を人数に比例させれば公平になる~~ → 試したら噂話の崩壊が39%→72%に悪化した。
  ばらばらに入ってくる感染者が、感染の波の同期を崩す役もしていた
- **20試合では崩壊率の比較に足りない**（誤差±10%ほど）。崩壊率で判断するときは100試合で取る

## 次にやること

作者が遊んだ所感（2026-09-23）: 対処するものが多すぎて雑に対応してしまう。数を減らし、動きを複雑にし、
街（障害物）で移動が変わるようにしてほしい。→ **街と目的地のある盤面に作り直す。**
設計は [docs/design-city.md](design-city.md)。作者と決めたこと: 30人前後／目的地を行き来＋時間帯で流れが変わる／
隔離は通れなくする（封鎖・迂回）／街は毎回同じ。

1. **段階1: 街・30人・目的地を行き来する動き・時間帯・駅からの流入**（着手中）
2. **段階2: 隔離＝封鎖。** 一度 Kiro が「壁」として試して逆効果だった方式なので、
   封鎖の手前に人が溜まらないようにする歯止めを入れる（設計文書の「前歴と歯止め」）
3. **段階3: バランスの取り直し**（PC とスマホの両方、崩壊率は100試合）
4. 演出・手応え（CHAIN / OUTBREAK）
5. 人の個性（スーパースプレッダー等）
