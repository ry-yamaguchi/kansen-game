# プロジェクト

**感染広がりラボ** — Web ブラウザですぐ遊べる、感染拡大を食い止めるリアルタイム介入ゲーム。

**正となる仕様は、作者が最初のチャットで渡した企画である。** 以下はセッションをまたいで
忘れないための要約にすぎない。食い違ったら作者の企画の側が正しい。

## 何を作るか

- 画面内を50〜100人の点（エージェント）が動き回る。状態は未感染・感染・回復の3つで、色で分かる
- 感染者と未感染者が近距離で接触すると確率で感染し、連鎖的に広がる
- プレイヤーは街のオペレーター。有限の「対策ポイント」を使って介入する
  （隔離エリア／ワクチン・治療エリア／緊急ロックダウン）
- 1ゲーム60〜90秒。終了時に最終感染率・最大同時感染者数・守れた人数・スコアを出し、
  ワンクリックでもう一度遊べる

## 崩してはいけないこと

- **「眺めるシミュレーション」ではなく「どこに、いつ介入するか」を判断するゲームである。**
  厳密な感染症モデルであることより、感染が広がっているのが一目で分かることを優先する。
- **対策ポイントは有限。全部使えば勝てる、にしない。** 迷いが生まれるバランスにする。
- 説明を読まなくても触れば分かること。PC とスマートフォンの両方で遊べること（タップ対応）。

## 技術

React + TypeScript。シミュレーションの描画は Canvas を使ってよい。
外部バックエンドは作らない。依存ライブラリは必要最小限にする。

## 進め方

**いきなり大量の機能を作らない。** まず「人が動く → 感染する → 介入できる → 勝敗が決まる」
までを実際に遊べる状態として完成させ、作者が触ってから次を決める。
特性持ちのキャラクター・ランダムイベント・コンボ演出は、MVP が遊べるようになってから検討する。

UI を作り込みすぎない。短時間で完成させることを最優先する。
