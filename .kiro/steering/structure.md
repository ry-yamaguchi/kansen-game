# ディレクトリ構成

```
src/
  sim/            シミュレーション中核（純粋・テスト可能・描画に依存しない）
    world.ts        都市・移動路・ゲーム状態の型
    model.ts        1ティック（1日）の SEIR 計算と都市間の伝播
    traits.ts       能力（変異）の定義と効果
    response.ts     人類側の対抗（発見・ワクチン進捗・ロックダウン）
    balance.ts      バランス定数（数値はすべてここ）
    rng.ts          シード付き乱数
    index.ts        外向きの API（状態を受けて次の状態を返す）
  ui/             描画と入力（Canvas・DOM）。sim の状態を読むだけで、計算はしない
  data/           マップ定義（JSON）。都市・人口・気候・医療水準・移動路
  main.ts         起動
tests/            Vitest
docs/             企画・設計メモ
.kiro/            steering と spec
```

## 分離の原則

- **`ui/` から `sim/` は呼んでよいが、`sim/` から `ui/` は呼ばない。** 依存は一方向である。
- ゲームのルールを `ui/` に書かない。画面を書き換えたらルールが変わる、という状態を作らない。
- マップは `data/` のデータに寄せる。都市を増やすのにコードを変えなくてよい形にする。
