# 言語設定

- ユーザーとのすべてのやり取りは、原則として **日本語** で行う。
- チャットの応答、説明、コメント、要約はすべて日本語で記述する。
- 仕様書（spec）、設計ドキュメント、要件定義なども日本語で作成する。
- コード内のコメントや説明も、可能な限り日本語で記述する。
- ただし、以下は元の言語（英語など）のまま扱う:
  - 変数名・関数名・クラス名などの識別子
  - ライブラリ名・コマンド名・技術用語の正式名称
  - エラーメッセージやログの原文を引用する場合
- ユーザーが別の言語で質問した場合でも、特に指定がなければ日本語で応答する。

## 文体

| 対象                                             | 文体                 |
| ------------------------------------------------ | -------------------- |
| コードのコメント、設計文書、コミットメッセージ   | 「である」調         |
| **画面に出る文言、エラーメッセージ**             | **「です・ます」調** |

画面の文言は遊ぶ人が読むものである。失敗を伝えるときは、原因と次にとれる行動を添える。
